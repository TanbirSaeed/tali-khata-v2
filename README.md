# Tally Khata V3

বাংলা ইন্টারফেসের অফলাইন-সক্ষম হিসাবের খাতা (PWA)।

## ফিচার
- কাস্টমার ও সাপ্লায়ার যোগ
- বাকি, জমা, বাকিতে কেনা ও পরিশোধ
- খরচের হিসাব
- পাবেন/দেবেন ব্যালেন্স ও ড্যাশবোর্ড
- JSON ব্যাকআপ/রিস্টোর
- প্রিন্ট / PDF হিসেবে সংরক্ষণ
- সার্ভিস ওয়ার্কার দিয়ে অফলাইন ক্যাশ

## চালানো
`index.html` সরাসরি খুললে মূল হিসাবের ফিচার চলবে। PWA ইনস্টল ও অফলাইন ক্যাশের জন্য HTTPS-এ হোস্ট করুন (যেমন GitHub Pages)।

## Android-এ ইনস্টল
HTTPS লিংক Chrome-এ খুলুন → মেনু (⋮) → Install app / Add to Home screen।

## গুরুত্বপূর্ণ
এই সংস্করণে ডেটা ওই ডিভাইসের ব্রাউজারের Local Storage-এ থাকে। ব্রাউজারের ডেটা মুছে গেলে হিসাব হারাতে পারে—নিয়মিত Backup ডাউনলোড করুন। এখনো ক্লাউড সিঙ্ক, লগইন, একাধিক দোকান/ব্যবহারকারী, পণ্য-স্টক মডিউল বা APK প্যাকেজিং যুক্ত হয়নি।
